# easyserp 1.0.0 验收记录

日期：2026-11-14（Asia/Shanghai）。本轮只接入现有公开搜索接口，没有修改服务实现或线上配置。

## 接入与搜索处理

- 37 项自动化测试通过，覆盖 CLI、MCP stdio、密钥文件、参数、分页、幂等恢复、重试、取消、429 等待、域名筛选和错误返回。
- 查询成功立即返回，不重复发起、不重复计量。临时失败默认最多补试两次；结果未知沿用相同请求身份，已确认终态且扣费为零时才能发起新尝试。
- 原始结果保留；供用户使用的结果按域名筛选、去重和排序。没有符合指定来源的结果时明确提示，不把范围外链接当作命中。
- pending、失败和结果未知分别返回，保留请求回执、尝试历史与已知费用。缺失费用字段时保持未知。
- 便携 Skill、MIT 与 ClawHub MIT-0 包、Claude 插件包已构建；Skill 校验通过。独立 npm tarball 安装后的 CLI 和 MCP 协议验证通过，npm 账号不是使用 ZIP/源码 Skill 的前提。
- Claude Code 的 marketplace 与插件元数据经官方 CLI 本地校验通过。

## 真实查询

固定脚本 `scripts/release-search-cases.mjs` 测了 12 组公共主题：品牌、开发框架、文档、中英文、葡语、自媒体选题和严格来源范围。

- 11 组获得 API 返回；1 组“自媒体 选题”补试至 3 次后仍不可用，并如实返回 `bing_empty_results`。
- 5 组得到满足本次来源条件的结果；其他指定来源组提示未命中，没有补造来源。
- Google 和 Bing 均有有效结果；中文与葡语查询均获得过有效结果。
- 12 组没有发现结果越过指定域名范围的情况。
- 本轮并发 3 个查询，总耗时约 30.7 秒。正常成功均只发起一次搜索；这是一轮查询记录，时延和可用性会随查询变化。

完整响应、幂等身份和复测文件只保存在本机忽略 Git 的 `.local/` 中。公开报告不包含凭据或用户浏览器数据。
